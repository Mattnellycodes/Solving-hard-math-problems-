# Solving Hard Math Problems

An attempt to make measurable progress on an unsolved mathematics problem using
AI-orchestrated research: many parallel hypothesis-testing agents, computational
search, and adversarial verification of every claim.

## Layout

- `docs/` — problem selection survey, problem dossier, hypothesis plans
- `docs/JOURNAL.md` — chronological research journal (every experiment, every result, including negative ones)
- `experiments/` — one directory per hypothesis, each with a `README.md`, code, and outputs
- `scripts/` — shared tooling
- `results/` — verified certificates / constructions / bounds

## Status

See `docs/JOURNAL.md` for the current state.
